# Changelog

## 0.1.0 (unreleased)

- First public version with ten skills: setup, session-end, see-it-work,
  reference-hunt, feature-demo, research, set-goals, port-feature, ship and
  fact-check.
- feature-demo: builds a tap-through demo of a feature in the app's own colours
  and fonts, so a flow can be seen and argued with before it is finished, with
  references for the preview harness and the traps that waste the most time.
- see-it-work templates: the test after edit hook, a test only seed link, smoke cases
  and a coverage check.
- Store traps reference with sources and verification status: 13 of 20 traps
  checked against official pages on 2026-10-11.
- Facts file for numbers that change, including store fees and Mobbin pricing.
- Contribution setup: templates, code owners and a validation check for pull requests.
