# Privacy

The Last Mile collects nothing. It has no server, no analytics and no account.

The skills run inside your own AI agent, on your machine or in your own cloud session,
with that agent's permissions. What they read and change stays in your project.

Some skills reach the internet when you use them:

- **fact-check, research, store-listing and others** open public web pages, such as
  Apple's and Google's own documentation, to check a rule or a fact.
- **connect-tools** helps you add official MCP servers from vendors you already use
  (RevenueCat, Sentry, Expo and others). You sign in to each one yourself, and that
  vendor's own privacy policy applies to it.
- **sync** copies the latest skills from this GitHub repo into your project.

If you report a rejection through a GitHub issue, what you write there is public on
GitHub. Leave out anything you don't want shared.

Questions: [open an issue](https://github.com/namedtoaster/the-last-mile/issues).
