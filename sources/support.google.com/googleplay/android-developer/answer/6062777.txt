# Test in-app billing and Age Signals API with application licensing
With application licensing, you can set up a list of Google Accounts (Gmail or Google Groups) to test your in-app billing and subscription integration as well as Age Signals API. Note that your own publishing account is always considered a licensed tester.

## Set up application licensing

To set up application licensing, start by adding your testers in Play Console.

- Sign in to Play Console.

- Go to the License testing page (Manage account > Play apps settings > Monetization settings > License testing).

- Choose your license testers by using either email lists or Google Groups.

- To use email lists: Select Email lists. Choose your license testers from the email lists shown, or click Create list to make a new one. Each email list can contain up to 2,000 email addresses.

- To use Google Groups: Select Google Groups. Enter Google Group email addresses (for example, yourgroup@googlegroups.com). All members of the specified Google Groups will be license testers. Unlike email lists, Google Groups do not have a user limit.

Tip: Email lists and Google Groups for license testing work in a similar way to managing testers for closed tests. For more information, see Set up an open, closed, or internal test.

- Click Save changes.

Once you're ready, make sure that:

- Your app has been published to the open, closed, internal test, or production track. We recommend that you publish your app to the internal test track. Make sure that your testers are also eligible to receive your release by following the instructions for managing testers by email address or using Google Groups.

- You've set up a test environment.

## Test in-app billing and subscriptions

You can purchase your own app, one-time product, or subscription as a test purchase. Once you've set up application licensing, authorized users can also purchase one-time products and subscriptions without charging their accounts.

Note: You must publish your one-time products and subscriptions before they can be tested.

For more information, see Test your Google Play Billing Library integration on the Android Developers site.

## Test Age Signals API

You can use debug builds with debug signatures without uploading a new version of your app. Once you've set up your application licensing, authorized users can bypass the APP_NOT_OWNED error ordinarily returned for sideloaded apps to test your live Age Signals API integration.

Before it can be tested, your application's package name must match the app that is configured for Google Play, and the active Google Account on the testing device must be registered as a license tester for your account.

For more information, see Play Age Signals overview on the Android Developers site.
