# RevenueCat Documentation

> RevenueCat is the most popular way to build, analyze, and grow in-app purchases and subscriptions on iOS, Android, and the web — no server code required. Append `.md` to any docs URL to fetch its clean Markdown for AI agents and LLMs.

This index is split by section so that every file fits in a single agent fetch. Each link below points to a section index listing that section's pages; fetch the section you need, then fetch its pages.

For the complete documentation as a single Markdown file, see [llms-full.txt](https://www.revenuecat.com/docs/llms-full.txt).
